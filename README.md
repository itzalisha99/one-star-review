A make.fun entry for **One-Star Review of Something Essential**: one deadpan
one-star review, 160 characters or fewer, of an everyday essential.

## The review

> Sleep takes a third of my life, charges me eight hours a night, and delivers a version of me that is still tired. One star.

## How it works

`main.py` (Python stdlib only, deterministic) writes the review to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–160 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
